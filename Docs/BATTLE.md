# MetaLab — схема проведения боя

## 1. Подготовка к серии боёв

До создания отдельных боёв создаются общие компоненты:

1. `ActionRulesRegistry` — реестр правил действий.
2. `AVAILABLE_ACTIONS` — общий неизменяемый набор доступных типов действий.
3. `BattleRules` — настройки проведения боя.

Создаются стратегии с передачей им общего набора действий:

```python
strategy_a = AgentStrategy(AVAILABLE_ACTIONS)
strategy_b = AgentStrategy(AVAILABLE_ACTIONS)
```

## 2. Подготовка конкретного боя

Для каждого боя:

1. Создаются два агента на основе `Build`.
2. Создаётся экземпляр `BattleEngine`.
3. В движок передаются:
   - `agent_a`;
   - `agent_b`;
   - `strategy_a`;
   - `strategy_b`;
   - `ActionRulesRegistry`;
   - `BattleRules`.

Один экземпляр `BattleEngine` отвечает за один бой.

## 4. Подробная логика раунда

### Шаг 1. Снимки состояния

Движок получает актуальные состояния обоих агентов.

Создаются два `AgentSnapshot`:

- `snapshot_a`;
- `snapshot_b`.

### Шаг 2. Формирование AgentState

Для стратегии A:

```python
state_a = AgentState(
    own_state=snapshot_a,
    enemy_state=snapshot_b,
)
```

Для стратегии B:

```python
state_b = AgentState(
    own_state=snapshot_b,
    enemy_state=snapshot_a,
)
```

Оба состояния отражают характеристики агентов на начало раунда.

### Шаг 3. Выбор действий

Обе стратегии получают свои состояния и вызывают:

```python
action_a = strategy_a.choose_action(state_a)
action_b = strategy_b.choose_action(state_b)
```

Каждая стратегия самостоятельно выбирает:
- тип действия;
- цель действия.

На этом этапе характеристики агентов ещё не изменяются.

### Шаг 4. Получение правил

Для каждого действия движок получает соответствующий экземпляр правил:

```python
rules_a = action_rules_registry.get(action_a.action_type)
rules_b = action_rules_registry.get(action_b.action_type)
```

### Шаг 5. Расчёт эффектов

Движок передаёт правилам состояние начала раунда и выбранную цель:

```python
effects_a = rules_a.calculate_effects(state_a, action_a.target)
effects_b = rules_b.calculate_effects(state_b, action_b.target)
```

Оба набора эффектов рассчитываются до применения любых изменений.

### Шаг 6. Применение эффектов

Движок применяет все рассчитанные эффекты.

Получатель определяется через `Effect.target`:

- `Target.SELF` — агент, совершивший действие;
- `Target.ENEMY` — противник агента, совершившего действие.

Для применения изменения вызывается:

```python
agent.apply_result(effect.result)
```

Важно: агент, который получил смертельный урон в текущем раунде, всё равно совершает уже выбранное действие. Поэтому нельзя прерывать применение эффектов только из-за смерти одного из участников.

### Шаг 7. Проверка завершения боя

После применения всех эффектов проверяется состояние агентов.

Возможные исходы:

| Состояние | Результат |
|---|---|
| Оба живы | Бой продолжается |
| Жив только A | Победа A |
| Жив только B | Победа B |
| Оба погибли | Ничья |
| Достигнут лимит раундов, оба живы | Победа обоих |

Если бой продолжается, начинается следующий раунд.

## 5. Важные принципы выполнения

1. **Одновременный выбор.** Оба агента выбирают действия до применения последствий.
2. **Общее исходное состояние.** Оба действия рассчитываются относительно характеристик на начало раунда.
3. **Одновременное применение.** Сначала рассчитываются все эффекты, затем они применяются.
4. **Действие после смерти.** Смерть агента в текущем раунде не отменяет уже выбранное им действие.
5. **Единый движок.** `BattleEngine` координирует процесс, но не содержит конкретных правил действий.
6. **Изоляция правил.** `ActionRules` рассчитывают эффекты, но не применяют их.
7. **Изоляция стратегии.** `AgentStrategy` выбирает действие и цель, но не исполняет их.

## 6. Границы ответственности

| Компонент | Ответственность |
|---|---|
| Build | Начальные характеристики |
| Agent | Текущее состояние и применение результатов |
| AgentSnapshot | Неизменяемый снимок характеристик |
| AgentState | Состояние обоих участников для стратегии |
| AgentStrategy | Выбор действия и цели |
| Action | Описание выбранного действия |
| ActionType | Тип действия |
| Target | Цель действия |
| ActionRules | Расчёт эффектов |
| ActionResult | Изменение характеристики |
| Effect | Результат и его получатель |
| ActionRulesRegistry | Соответствие типа действия правилам |
| BattleRules | Настройки боя |
| BattleEngine | Управление ходом боя |
| BattleResult | Итог боя |

## 7. Что важно проверить тестами BattleEngine

- Оба агента выбирают действия до применения эффектов.
- Оба действия рассчитываются на основе исходного состояния раунда.
- Эффекты обоих действий применяются.
- Агент совершает действие, даже если погибает в этом раунде.
- Правильно определяется победитель.
- Правильно определяется ничья.
- При достижении лимита раундов оба выживших агента признаются победителями.
- Бой не запускается повторно на том же экземпляре `BattleEngine`.
